# Agencia de Turismo "Rumbo Sur" - Sistema de Gestión

## Descripción del Sistema
Este proyecto es una aplicación desarrollada en Java para gestionar las operaciones de la Agencia de Turismo "Rumbo Sur". El sistema permite administrar la creación y validación de distintos tipos de tours (Aventura, Cultural, Naturaleza), registrar pasajeros, asignar guías y vehículos a salidas específicas, y procesar reservas, pagos y cancelaciones aplicando reglas de negocio formales.

## Requisitos Técnicos
* **Lenguaje:** Java 17 o superior.
* **Entorno:** Cualquier IDE compatible (IntelliJ IDEA, Eclipse, NetBeans) o ejecución mediante consola.

## Instrucciones de Instalación y Ejecución
1. Clonar el repositorio en la máquina local utilizando Git:
   `git clone [URL_DEL_REPOSITORIO]`
2. Abrir el proyecto en el IDE de preferencia.
3. Asegurarse de tener configurado el JDK 17 o superior en las propiedades del proyecto.
4. Localizar la clase principal (`Main.java` u otra que se designe para el inicio) dentro de la carpeta `src`.
5. Compilar y ejecutar la clase principal para iniciar la interfaz por consola o gráfica.
